# Mascotes

- `clawd.svg` é o Clawd, o mascote do Claude Code, redesenhado em pixels a partir da arte em blocos que o Claude Code mostra ao abrir no terminal. A cor é o laranja da marca Claude (#D97757).
- `codex.webp` é o ícone do app Codex (a nuvem com `>_`), copiado de `ChatGPT.app/Contents/Resources/icon-codex-light.png`. A OpenAI não tem um mascote oficial único para o Codex; os "Codex Pets" são personagens que cada usuário escolhe ou cria.

As marcas e personagens pertencem à Anthropic e à OpenAI. O site os usa só para dizer com quais ferramentas os projetos foram feitos.
